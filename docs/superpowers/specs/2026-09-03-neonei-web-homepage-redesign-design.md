# NeoNEI-Web 主页三栏经典游戏化与多端自适应设计规格说明

**创建日期**：2026-09-03

**影响工程**：`e:\codex\ae2\web\` (`NeoNEI-Web`)

---

## 1. 目标与背景

当前 `NeoNEI-Web` 具有出色的 `NativeSurface` 60 FPS 纯像素画布渲染能力，但在主页结构上仅为极简原型，缺乏经典 Minecraft NEI 原汁原味的三栏空间秩序感与交互灵魂。
本项目标是将旧版 `NeoNEI` 成熟的经典首页布局与交互逻辑全面重构并移植至 `NeoNEI-Web`，同时解决跨分辨率（4K、2K、1080p、笔记本、iPad/平板、手机）下的视觉平衡感，打造具备工业级沉浸感的高性能 Web NEI。

## 2. 整体视口架构与多端响应式断点体系

### 2.1 三层自适应断点规则
1. **大屏桌面端（视口宽度 $\ge 1280\text{px}$）**：
   * **经典三栏结构**：
     * **左侧模组控制轨（Left Rail）**：宽度约 $220\text{px}$，可一键折叠；包含模组下拉筛选、重置过滤器与系统设置齿轮；
     * **中间配方主舞台（Center Stage）**：占据约 $42\% \sim 50\%$ 视口宽度；默认留空呈现带有微弱暗黑工业金属纹理的静音态，点击物品时居中浮动展开配方坞站（Recipe Dock）；
     * **右侧全景物品矩阵（Right Matrix）**：占据约 $32\% \sim 38\%$ 视口宽度；毫秒级容量感知自动铺满；
     * **底部搜索条（Bottom Search）**：横向绝对居中，留出左右安全边距。
2. **平板与紧凑笔记本（视口宽度 $768\text{px} \sim 1279\text{px}$）**：
   * 左侧模组轨自动缩拢为 $48\text{px}$ 的极简图标浮动条（Icon Rail）；
   * 中间配方坞站与右侧物品栏按 $55\% : 45\%$ 平衡分配空间；
   * 配方缩放按舞台可用区域自动计算最佳比例。
3. **移动手机端（视口宽度 $< 768\text{px}$）**：
   * 主视口为单列全屏全景物品矩阵；
   * 底部搜索框固定吸底，自动监听移动端软键盘呼出上移防遮挡；
   * 点击物品后，配方坞站以 **拟真底部抽屉（Bottom Sheet）** 平滑滑出，支持下拉关闭与左右滑动手势切页。

### 2.2 居中默认状态视觉重心设计
* 中间区域在未选择物品时默认不显示任何配方框；
* 渲染高对比暗黑工业底纹（`#0D1117` 结合微量光晕与点阵），中央微弱浮动提示文字：“在右侧点击物品查看合成（R）或用途（U）”；
* 底部附带最近查看的 5 个物品快捷徽标（Quick Chips），点击可直接调出对应配方。

## 3. 右侧全景物品浏览器设计 (NEI Item Panel)

### 3.1 顶部控制器与“星微之光”翻页
* **顶部功能栏**：
  * `Recipe` 快捷键提示按钮；
  * “星微之光”胶囊翻页器（如 `01 / 48`），配合极简矢量左右微调箭头；
  * 支持悬浮在物品栏任意位置使用鼠标滚轮进行无级平滑翻页。
* **最近浏览历史条（HomeHistoryStrip）**：
  * 常驻于物品网格上方，横向陈列最近点击查看过的最多 8 个物品图标，点击可立即跳转。

### 3.2 动态容量感知算式（彻底消除半截留白）
* 采用 `ResizeObserver` 实时监测右侧物品容器的物理像素尺寸：
  $$\text{cols} = \max\left(1, \lfloor (\text{containerWidth} - \text{padding}) / (\text{itemSize} + \text{gap}) \rfloor\right)$$
  $$\text{rows} = \max\left(1, \lfloor (\text{containerHeight} - \text{headerHeight} - \text{padding}) / (\text{itemSize} + \text{gap}) \rfloor\right)$$
  $$\text{pageSize} = \text{cols} \times \text{rows}$$
* 无论视口如何缩放、拉伸或旋转，物品矩阵始终精确填满当前视口，避免产生页面纵向滚动条。

### 3.3 交互与 Tooltip 契约
* **左键点击**：以该物品作为产物查询所有合成配方（`R` / Recipes）；
* **右键点击**：以该物品作为原料查询所有下游用途配方（`U` / Usages）；
* **悬浮浮动 Tooltip**：还原 Minecraft 原版暗紫边框半透明浮层，显示物品中文名、英文名、`ID:Meta`、所属模组、矿物词典（OreDict）标签。

## 4. 中间经典 NEI 配方坞站 (Center Recipe Dock)

### 4.1 拟真游戏外壳与机种 Tab 栏
* **机种类别栏（Machine Category Tabs）**：
  * 位于配方框顶部，横向平铺当前物品参与的所有机器类型图标（工作台、组装机、电弧炉、高炉、化学反应釜等）；
  * 图标高亮显示当前激活状态，并带该机器名下配方数量角标（如 `组装机 (12)`）。
* **配方子翻页器（Sub-Pager）**：
  * 配方框右上角展示 `Page 01 / 04`，支持点击左右箭头或滚轮在同机种下翻页。
* **立体浮雕底框**：
  * 外框采用沉浸式暗黑工业石质浮雕风格（`#161B22` / `#21262D`），拥有 tactile 凹凸金属质感斜面边框；
  * 右上角配备 `×` 关闭按钮，左上角配备 `←` / `→` 历史回溯按钮。

### 4.2 纯像素 NativeSurface 嵌入与无限下钻
* 配方内部核心区域由 `NativeSurface.vue`（纯 Canvas）进行毫秒级绘制；
* 保持 60 FPS 刷新率与 20Hz 真实流体/物品动画；
* **无限配方树下钻**：在配方内部任意输入/输出槽位上：
  * 左键点击：下钻查询该原料的合成配方；
  * 右键点击：查询该原料的后续用途；
  * 支持键盘 `Backspace` 随时一键回溯至上一层配方。

---

## 5. 底部搜索栏、快捷键与 GUI 缩放系统

### 5.1 底部经典居中搜索条
* 横向绝对居中对齐，采用 NEI 经典暗色带立体光泽输入框；
* 语法支持：
  * 普通文本模糊匹配（中英文）；
  * **拼音首字母过滤**（输入 `jcdl` 毫秒级命中 `基础电路板`）；
  * **`@mod` 模组过滤**（输入 `@gregtech` 过滤所有格雷物品）；
  * **`$ore` 矿词过滤**（输入 `$circuit*` 过滤矿词电路）；
* **NEI 经典交互**：右键点击搜索框立即全选并清空内容。

### 5.2 全局快捷键系统
* 鼠标悬浮任意槽位或物品格：
  * 按 **`R`**：查询合成（Recipes）；
  * 按 **`U`**：查询用途（Usages）；
* 按 **`Esc`**：关闭当前配方坞站（返回默认留空平衡态）；
* 按 **`Ctrl + F`**：光标聚焦底部搜索框；
* 按 **`Backspace`**：配方历史回退。

### 5.3 游戏同款 GUI 缩放滑块 (GUI Scale)
* 位于右上角设置面板中，支持实时无级滑动与 4 档快捷预设：
  * **自动 (Auto)**：根据 DPI 与屏幕宽高自动计算最优格点尺寸；
  * **紧凑 (Compact, 36px)**：超高密度物品矩阵；
  * **标准 (Normal, 44px)**：舒适桌面体验；
  * **大号 (Large, 54px)**：超清 4K 或远距大屏体验；
* 状态持久化于浏览器的 `localStorage` 中。

## 6. 性能与技术契约

* **帧预算**：任何屏幕缩放与翻页操作下，帧渲染耗时均严格限制在 $\le 16.6\text{ms}$（60 FPS）；
* **轻量化约束**：前端打包总体积持续保持在 $< 50\text{KB}$（gzip）；
* **降级策略**：若某物品未命中动态图集，自动平滑回落至高质量矢量像素槽位与文字标识，绝不出现 DOM 白屏或崩溃。

## 7. 验证与测试计划

1. **多断点视口布局测试**：
   * 验证 `3840x2160` (4K)、`1920x1080` (标准桌面)、`1366x768` (紧凑笔记本)、`1024x768` (iPad 竖屏)、`390x844` (iPhone 移动端) 下的布局平衡与自适应容错；
2. **容量感知计算测试**：
   * 验证在动态缩放浏览器窗口时，`ResizeObserver` 计算出的 `cols * rows` 能严格填满右侧且无纵向滚动条；
3. **NEI 核心功能回归测试**：
   * 验证物品左键查 R、右键查 U、拼音搜索、右键清空搜索栏、键盘 `Esc` 与 `Backspace` 历史栈跳转；
4. **自动化单元测试与全量构建**：
   * 运行 `npm test` 与 `npm run build`，确保构建零警告且通过所有单测。
